## Shortlist — best fit for a solo entrant whose strength is operating AI
## agents, checking claims, and running structured evals (not ML training)

### 1. Track 1 — FlipRate (recommended first pick)
Measure how a model's answer and stated confidence change across one, two
and three escalating rebuttals, separating warranted updating from
capitulation. Builds on SycEval / ELEPHANT (single-turn agreement already
measured; multi-turn flip curves are the gap). Doable in a weekend with API
calls + a small scenario set + a transparent rubric; no training needed.
Judging fit: clear metric, quantitative results, obvious novelty vs
single-turn benchmarks.

### 2. Track 2 — Citation Binder (small, shippable tool)
Tool that locates each cited source and verifies whether it genuinely
supports the specific claim, with per-citation verdicts and quoted passages.
Evaluation data exists (AVeriTeC). Fits how Muse already works (claim-by-
claim verification) and produces a demoable product in 3 days.

### 3. Track 3 — Crux Mapper (no ML skills needed)
Short async AI interviews with each group member, extract claims and
probabilities, render a disagreement map: shared ground, genuine cruxes,
internal inconsistencies. Cf. Habermas Machine (Science 2024), which drafts
agreement — this maps disagreement instead. Strongest if the user can supply
a real small group / dispute to test on; otherwise use scripted scenarios.

## Not shortlisted (and why)
- Track 4 "Do their numbers match?" (parliamentary transcripts vs stats):
  interesting, but sourcing clean Indonesian transcript + stats pairs in a
  weekend is the riskiest data step.
- Track 2 Track-Record Ledger / Tamper-Evident Action Recorder: bigger
  builds; ledger needs a consumer to matter, recorder needs framework
  instrumentation — too much for a solo weekend.
- Track 1 Confidence Audit / MASK-style evals: solid but closer to existing
  benchmarks (ForecastBench, consistency checks), so novelty is harder to
  show than FlipRate's multi-turn gap.
